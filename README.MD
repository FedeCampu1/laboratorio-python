# Laboratorio Python

## Instalación

1. Clonar el repositorio

2. Crear y activar un entorno virtual:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```

3. Instalar las dependencias:
   ```powershell
   pip install -r requirements.txt
   ```

## Levantar el servidor

```powershell
fastapi run app.py
```
